# Changelog

All notable changes to EagleECS will be documented here.

## [0.1.0] - Initial Release

### Added

- Lightweight Entity-Component-System library for JavaScript
- Integer entity IDs
- Non-reusable entity IDs
- Entity lifecycle management
- Component definitions with `defineComponent()`
- Component storage and management
- Entity/component lifecycle validation
- AND-based component queries
- Reusable query views
- Query evaluation at iteration time
- Smallest-store query optimization
- System registration and removal
- Ordered system execution
- Delta-time support
- World mutation from systems
- Public package API through `src/index.js`
- Native ES module support
- Node.js test suite
- npm package configuration
- Package documentation
